# 🛍 Local Store Ecommerce

## Overview
A Flask-based Local Store Ecommerce web application where users can register, log in, browse products, add items to the cart, checkout, and view order history.

## Features
- User Registration
- User Login & Logout
- Product Listing
- Product Search
- Shopping Cart
- Remove from Cart
- Checkout
- Order History
- Admin Dashboard
- Responsive Design

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2

## Installation

1. Clone the repository:
```bash
git clone <repository-url>
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the application:
```bash
python app.py
```

4. Open your browser and visit:
```
http://127.0.0.1:5000
```
